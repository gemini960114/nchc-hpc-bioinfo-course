# 快速上手：只想趕快跑分析，不想先讀完四份文件

如果你已經有 GP1 核心設施帳號（計畫代號 `MST109178`），只想盡快跑起分析，照這三步驟做就好。
遇到問題再回來查下面的「卡住了怎麼辦」對照表，不用一次把 Module 0 其他四份文件從頭讀完。

---

## Step 1：登入 + 啟用環境

先在本機 `~/.ssh/config` 設好 `t3-c4` 這個 Host 別名（設定內容見
[TWCC_Taiwania3_GP1生醫節點_使用手冊.md](TWCC_Taiwania3_GP1生醫節點_使用手冊.md) 第 2.1 節），
之後不管終端機還是 Antigravity IDE 的 Remote SSH 都能直接用 `t3-c4` 連線：

```bash
ssh t3-c4
source /work/$USER/Miniconda/bin/activate rachis-qiime2-2026.7   # 依實際環境名稱調整
```

## Step 2：用 Antigravity IDE 開 notebook，選對 kernel

1. Antigravity IDE 連上 `t3-c4.nchc.org.tw`（Remote-SSH）
2. 開任一 `class/` 底下的 `.ipynb`
3. 右上角 kernel 選擇器 → **Select Another Kernel → Jupyter Kernel** → 選你註冊過的環境
   （這一步最常卡住，見下方對照表第 1 條）

## Step 3：跑分析

三選一，看你要做哪種分析：

| 想做的分析 | 開這份 notebook |
|---|---|
| 定序資料品質檢查 | [../01_fastqc_multiqc/01_fastqc_multiqc_demo.ipynb](../01_fastqc_multiqc/01_fastqc_multiqc_demo.ipynb) |
| 16S 微生物體分析（QIIME2） | [../02_qiime2_moving_pictures/qiime2_moving_pictures_tutorial.ipynb](../02_qiime2_moving_pictures/qiime2_moving_pictures_tutorial.ipynb) |
| 宏基因體功能性分析（HUMAnN3） | [../03_singularity_humann3/03_humann3_demo.ipynb](../03_singularity_humann3/03_humann3_demo.ipynb) |

notebook 裡的 cell 一格一格往下執行即可，不用先讀完整份教學文件。
正式資料量大、要跑久一點的分析，改用同資料夾裡的 `run_*.sh` + `slurm_*.sh` 兩個腳本，用 `sbatch slurm_*.sh` 送出。

## 什麼時候該回去讀完整的四份文件

快速上手適合「環境已經有人幫你裝好、你只是要跑分析」的情境。以下狀況才需要回頭讀完整文件：

- **要從零裝一個新的分析工具環境** → 讀 [conda_miniconda_qiime2_install.md](conda_miniconda_qiime2_install.md)
- **Antigravity IDE / Jupyter 本身還沒裝好** → 讀 [Jupyter_Notebook_Tutorial.md](Jupyter_Notebook_Tutorial.md)
- **要申請帳號、搞懂計費、調整儲存空間額度** → 讀 [TWCC_Taiwania3_GP1生醫節點_使用手冊.md](TWCC_Taiwania3_GP1生醫節點_使用手冊.md) 全文
- **要自己把一份新的官方教學轉成 notebook** → 讀 [Qiime2_VSCode_Jupyter_教學.md](Qiime2_VSCode_Jupyter_教學.md)
